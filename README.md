# Cybersecurity Animated Explainer (Arabic)

An 8-scene animated explainer on how the internet works, common threats, and how to defend against them.

Live demo: https://ramasaleh986.github.io/cyber-animation/

## Topics
- Packet journey and MITM attacks
- Encryption and the TLS handshake
- Phishing, ransomware, DDoS
- The CIA triad
- Defense in depth
- Incident response
